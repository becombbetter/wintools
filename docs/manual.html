快速开始

01运行 WinCapture.exe
02点击主界面功能或使用快捷键
03编辑后复制、保存或置顶

关闭主窗口不会退出程序。WinCapture 会继续在系统托盘运行；右键托盘图标可彻底退出。

选择截图区域时按 Esc 或单击鼠标右键可以取消。延时截图可在设置中选择 3、5 或 10 秒。

编辑与马赛克

截图完成后自动进入编辑器。工具栏提供画笔、高亮、箭头、矩形、椭圆、文字、编号、马赛克、模糊、遮挡和裁剪。

  • 马赛克、模糊、遮挡和裁剪：按住鼠标拖出处理区域。
  • 文字：选择文字工具后，在图片中单击并输入内容。
  • 编号：每次单击生成递增编号，适合制作操作说明。
  • 撤销与重做：使用编辑器右上角的弯箭头按钮。
  • 保存：支持 PNG 和 JPEG；PNG 更适合界面截图。

长截图

按 Ctrl + PrintScreen 启动，框选可滚动的内容区域，随后会出现一个悬浮面板。

  1. 先把页面滚动到长截图的起点，再框选区域。
  2. 框选完成后，用滚轮滚动目标内容，WinCapture 会实时把新增内容拼到长图末尾。
  3. 面板中可以看到已拼接段数、当前高度和缩小预览；拼错时可以点“撤销一段”回到上一屏。
  4. 滚到内容结尾后点“完成”或按 Enter，结果会先进入长截图预览窗口；按 Esc 或“取消”则放弃本次长截图。

拼接依靠相邻两屏的重叠部分对齐，因此每次滚动最好保留约四分之一屏以上的重叠内容。

单次滚动超过约一屏时会找不到重叠，面板会提示“往回滚一点”，此时往回滚动即可继续，已拼接的内容不会丢失。页面吸顶导航只会保留一次，吸底工具栏不会被重复拼接。动态视频和持续动画区域会影响对齐，建议避开。

悬浮面板不会被截进长图，也不会抢走目标窗口的焦点，可以放心让它盖住页面边缘。

长截图预览与缩放

长图动辄上万像素高，直接进编辑器不方便先看整体，所以完成后会先打开预览窗口。预览窗口顶部是缩放控制，中间可滚动查看整张长图，底部是常用操作。

  • 缩放百分比：中间的 − / + 按档位缩放，两个按钮之间实时显示当前百分比（如 70%）。
  • 预设档位：适应宽度（整幅长图横向铺满窗口，打开时默认使用）、50%、100%（原始大小）、200%。
  • Ctrl + 滚轮：以鼠标位置为锚点连续缩放；Shift + 滚轮横向滚动。
  • 快捷键：Ctrl+0 适应宽度，Ctrl+1 原始大小，Ctrl++ / Ctrl+- 缩放，Esc 关闭。
  • 鼠标：按住左键拖动可平移；在图上双击可在“适应宽度”和“100%”之间切换。
  • 底部操作：OCR 识别、置顶贴图、复制、编辑标注、保存（PNG / JPEG / PDF）、关闭。点“编辑标注”会另开编辑器，预览窗口可以留在旁边对照。

“100%”表示长图的一个像素对应屏幕的一个物理像素，因此在高 DPI 缩放的屏幕上，100% 下的画面会比“适应宽度”小。

录屏

录制范围支持主显示器、选择区域和选择窗口。视频采用 H.264 编码并输出 MP4。

  • 系统声音与麦克风可独立启用。
  • 可选择 24、30 或 60 FPS，以及 4、8 或 16 Mbps 码率。
  • 录屏控制条不会出现在支持排除捕获的 Windows 11 画面中。
  • 暂停期间不计入录制时长，单击方形按钮完成并保存。

Windows 11 N 版需要安装 Media Feature Pack。首次录屏若提示缺少运行库，请安装 Microsoft Visual C++ 2015-2022 Redistributable x64。

OCR 与置顶贴图

在编辑器中单击“OCR 识别”，识别结果会显示在独立窗口并自动复制到剪贴板。识别语言取决于 Windows 已安装的语言包。

“置顶贴图”会把当前截图保持在其他窗口上方。拖动图片可移动，右上角按钮可切换透明度或关闭。

设置与文件

截图默认保存在“图片\WinCapture”，录屏默认保存在“视频\WinCapture”。保存目录、延时截图、声音、鼠标和开机启动均可在设置中修改。

长截图默认由你手动滚动；如果希望程序代替你滚动并拼接，可在设置中勾选“长截图自动滚动”，此时程序会自己发滚轮，并在画面停止滚动后才拼接。

主界面的最近文件列表显示最新截图和录屏，双击即可打开。设置文件位于 %LocalAppData%\WinCapture\settings.json。

常见问题

管理员窗口无法截图

普通权限程序不能稳定捕获更高权限窗口。退出 WinCapture 后，以管理员身份重新运行。

视频或安全界面显示黑色

DRM 视频、Windows 安全桌面和主动禁止捕获的窗口无法录制，这是系统安全限制。

快捷键没有响应

快捷键可能被其他程序注册。仍可从主界面或托盘菜单启动对应功能。

多显示器区域录屏

区域录屏必须位于同一显示器内。跨显示器截图不受此限制。

长截图提示“往回滚一点”

说明当前这一屏和已拼接内容的重叠不足（通常是单次滚动超过一屏）。往回滚动到与上一屏有重合的位置再继续即可，已拼接的部分不会丢失。内容高度重复的列表可能无法可靠对齐，可以缩小选择范围避开重复区域。
